Voiceboard - Azure 목소리 설정 방법 (0.1.7)
==========================================

먼저 알아둘 것
--------------
Azure Speech API 키는 비밀번호처럼 보관하세요.
채팅, GitHub, 친구에게 보내는 설치파일에 키를 넣지 마세요.
친구도 각자의 Azure 계정과 키를 쓰는 것을 권장합니다.

Voiceboard는 온라인 목소리를 만들 때 입력 문장을 Microsoft Azure로 전송합니다.
본 프로그램은 Azure 사용료를 대신 결제하거나 무료 사용량을 늘려 주지 않습니다.

1. Azure 계정 만들기
--------------------
아래 주소를 브라우저에서 엽니다.
https://azure.microsoft.com/free/

Microsoft 계정으로 가입합니다.
지역과 계정에 따라 전화번호, 본인 확인, 결제수단 등록이 필요할 수 있습니다.
가입 중 표시되는 조건을 확인하세요.

2. Speech 리소스 만들기
-----------------------
Azure 포털을 엽니다.
https://portal.azure.com/

위 검색창에 Speech 또는 음성 서비스를 검색합니다.
Speech 서비스의 만들기를 선택합니다.
포털 표기가 변경된 경우 공식 빠른 시작의 Speech 리소스 생성 안내를 참고하세요.
일반 Foundry 프로젝트만 만드는 것이 아니라, 키를 발급할 수 있는 Speech 리소스가 필요합니다.

입력 예:
- 구독: 본인이 만든 Azure 구독
- 리소스 그룹: 새로 만들기 > voiceboard
- 이름: voiceboard-speech 등 사용 가능한 이름
- 지역: Korea Central / 한국 중부
- 가격 책정 계층: Free F0

무료 이용이 목적이라면 F0를 선택하세요.
F0가 보이지 않는다고 S0를 대신 선택하지 마세요. S0는 유료 계층입니다.
검토 및 만들기 > 만들기를 누르고 배포가 끝날 때까지 기다립니다.

3. 키와 지역 확인하기
---------------------
완료된 리소스로 이동합니다.
리소스 관리 > Keys and Endpoint / 키 및 엔드포인트를 엽니다.

필요한 값은 두 개입니다.
- KEY 1 또는 KEY 2 중 하나
- Location/Region / 위치 또는 지역의 코드

한국 중부를 골랐다면 지역 코드는 koreacentral입니다.
일본 동부는 japaneast, 미국 동부는 eastus입니다.
지역은 반드시 해당 키가 발급된 리소스의 지역과 같아야 합니다.
엔드포인트 전체 주소나 구독 ID를 지역 또는 API 키 칸에 넣지 마세요.

4. Voiceboard에 입력하기
------------------------
Voiceboard 0.1.7 이상을 설치하고 실행합니다.
기존 앱이 실행 중이면 알림 영역 아이콘 우클릭 > 종료로 완전히 종료한 후 설치하세요.

왼쪽 설정 > 엔진에서 Azure Speech를 선택합니다.
엔진 오른쪽의 열쇠 아이콘(Azure 키 및 지역)을 누릅니다.
지역 코드와 API 키를 입력하고 저장을 누릅니다.
연결 확인을 눌러 한국어 목소리 목록을 읽을 수 있는지 확인합니다.
연결 확인은 목소리 목록 조회이며, 실제 음성을 만든 테스트는 아닙니다.

창을 닫고 목소리를 고릅니다.
- SunHi: 기존에 사용하던 한국어 여성 목소리
- JiMin, SeoHyeon, SoonBok, YuJin: 다른 한국어 여성 목소리

말하기에 짧은 문장을 입력하고 Enter로 송출합니다.
Space+Enter 빠른 입력창도 같은 Azure 엔진과 목소리를 사용합니다.
Discord에서 듣는 상대방과 소리 크기와 발음도 확인하세요.

5. 무료 사용량과 요금
---------------------
2026-10-16 확인한 Azure 공식 요금표 기준:
Free F0의 Neural Text to Speech는 매월 500,000자 무료입니다.
다른 제품, HD 모델 또는 유료 S0 계층의 요금과 혼동하지 마세요.
Voiceboard에서 제공하는 기본 한국어 선택지는 일반 Neural 목소리입니다.
요금과 제공량은 변경될 수 있으므로 아래 공식 페이지를 확인하세요.
https://azure.microsoft.com/en-us/pricing/details/speech/

앱에는 Azure 과금/잔여량을 실시간 조회하는 기능이 없습니다.
사용량과 요금은 Azure 포털에서 확인하세요.

6. 문제 해결
-------------
키 미등록:
설정 > Azure 열쇠 아이콘에서 키와 지역을 저장합니다.

인증 실패:
키에 다른 값이 섞이지 않았는지, 해당 리소스의 지역과 일치하는지 확인합니다.
리소스의 네트워크 접근 정책이 외부 요청을 막는지도 확인합니다.

사용 한도 또는 요청 횟수 제한:
무료 사용량 또는 요청 속도 제한일 수 있습니다. Azure 포털 사용량을 확인하세요.
연속 요청은 잠시 쉬었다 다시 보내세요.

저장된 키를 읽지 못함:
다른 Windows 사용자나 PC에서 가져온 암호화 파일은 읽을 수 없을 수 있습니다.
본인 계정에서 키를 다시 저장하세요.

키 삭제:
Azure 설정 창의 휴지통 아이콘으로 이 PC에 저장한 키를 삭제합니다.
이 동작은 Azure 리소스를 삭제하거나 서버의 키를 폐기하지 않습니다.
키가 유출되었다면 Azure 포털에서 재생성해야 합니다.

Azure 장애가 나도 Windows나 다른 목소리로 자동 변경하지 않습니다.
전송에 실패한 문장은 복원되고 빠른 입력창은 다음에 직접 열 때 오류가 표시됩니다.

7. 저장 위치와 보호 범위
------------------------
%APPDATA%\discord-local-voiceboard\azure-credentials.json

키는 Electron safeStorage / Windows DPAPI로 암호화해 일반 library.json과 분리합니다.
키를 앱 화면에 다시 표시하거나 음성 요청 오류 로그에 출력하지 않습니다.
다만 같은 Windows 사용자 권한으로 실행되는 악성 프로그램까지 막는 보호는 아닙니다.
암호화 파일도 친구에게 공유하지 마세요.

9. 이번 수정본 검증 범위
------------------------
키 없는 상태 처리, 모의 Azure 응답, 암호화 저장, UI, 패키징을 검증합니다.
실제 Azure 음성 생성과 Discord 상대방 청취는 본인의 키 등록 후 확인해야 합니다.
