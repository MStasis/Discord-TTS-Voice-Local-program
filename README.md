밤에 마이크 못쓸때 디코하려고 만든거

디코 봇은 없는곳이 많아서 봇 없이 TTS읽어주는 프로그램 필요해서 만듦

가상케이블 필요한데 안깔려있으면 프로그램 켰을때 안내 뜰거임

설치하고 세팅 <- 누르면 바로 TTS읽어줄 수 있는 상태가 됨
해제 <- 누르면 마이크 쓸 수 있는 상태로 돌아옴

**디코 마이크 입력장치 '기본' 으로 놓고 써야됨**

세팅: Discord 잡음 제거 없음, 에코 억제 끔, 자동 입력 감도 끔, 감도 -95dB
해제: Discord 잡음 제거 Krisp, 에코 억제 켬, 자동 입력 감도 끔, 감도 -55dB

Discord 데스크톱 앱을 실행한 상태에서 사용하세요. 음성 설정 화면이 열릴 수 있습니다.
Discord 버전이나 창 상태 때문에 자동 적용을 확인하지 못하면 앱에 오류가 표시됩니다.
케이블 설정과 Discord 설정은 별도로 적용되므로 오류가 나면 Discord 음성 설정을 확인하세요.

[추가 기능]
- 최근 대화: 실제 재생에 성공한 문장 최대 3개 자동 보관, 다시 전송, 삭제
- Enter 전송 즉시 입력창 비우기. 생성 중 새로 입력한 문장은 유지
- 생성 실패 시 전송했던 문장을 입력창에 복원
- 사운드보드 기능

최근 대화는 앱을 다시 켜도 유지되며, 네 번째 문장이 추가되면 가장 오래된 문장은 삭제됩니다.
이전 버전의 수동 저장 문장은 데이터 파일에 유지되지만 최근 대화 화면에는 표시하지 않습니다.
