해제: Discord 잡음 제거 Krisp, 에코 억제 켬, 자동 입력 감도 끔, 감도 -55dB

Discord 데스크톱 앱을 실행한 상태에서 사용하세요. 음성 설정 화면이 열릴 수 있습니다.
Discord 버전이나 창 상태 때문에 자동 적용을 확인하지 못하면 앱에 오류가 표시됩니다.
케이블 설정과 Discord 설정은 별도로 적용되므로 오류가 나면 Discord 음성 설정을 확인하세요.

[추가 기능]
- 0.1.8: 송출 볼륨과 내 듣기 볼륨을 독립적으로 저장 / 조절. 송출 볼륨은 기존 말하기 하단, 내 듣기 볼륨은 설정 > 출력에 있음. TTS / 빠른 입력 / 사운드보드 / YouTube 재생에 공통 적용하며 재생 중 변경과 내 듣기 음소거 지원
- 0.1.7: Azure Speech 공식 API 연결. 설정에서 Azure Speech 선택 후 열쇠 아이콘으로 키와 지역 저장 / 연결 확인 / 삭제. SunHi, JiMin, SeoHyeon, SoonBok, YuJin 한국어 여성 음성 지원
- 새 설치의 기본 엔진은 Azure. 기존 Edge / Windows 선택과 케이블 설정은 유지. 키는 Windows 암호화 저장소로 별도 보관하며 배포 파일에 넣지 않음. 자세한 가입 / F0 / 키 발급 안내: Azure설정방법.txt
- 0.1.6: 온라인 TTS 실패 시 Windows 목소리로 자동 변경하지 않음. 전송은 멈추고 문장을 복원하며, 빠른 입력창을 다음에 열면 실패 이유가 표시됨. 로컬 음성은 설정에서 Windows Local을 직접 선택한 경우에만 사용
- 0.1.5: 트레이 / 빠른 음성 입력창 / 작업표시줄 아이콘 통일. 입력창은 작업표시줄 위 중앙에서 220ms 슬라이드로 열림 (동작 줄이기 설정에서는 즉시 표시)
- Discord 자동 설정은 기존 값 유지. 이미 다른 값인 항목의 불필요한 사전 대기와 클릭 후 고정 대기를 줄였으며, 변경 후 상태 확인 / 최대 3회 재시도는 유지
- 0.1.3: 한 화면 말하기 UI. 최근 대화 / 사운드 / 설정은 왼쪽 메뉴로 여는 하단 패널
- 패널 윗부분, 같은 메뉴, Escape로 닫기. 작성하던 문장은 그대로 유지
- 엔진 / 목소리 / 속도 / 피치 / TTS 볼륨 / 출력 장치 / 내 듣기는 설정 패널에 있음
- 사운드는 페이지당 6개 표시. 많아도 페이지 이동으로 접근하며 화면 스크롤 없음
- 게임 중 Space+Enter: 스페이스를 누른 채 Enter를 누르고 두 키에서 손을 떼면 음성 입력창 열기 (앱 실행 중에만 동작, 0.1.4부터 Shift+Enter 대체)
- 설정 > 창을 닫아도 백그라운드 실행: 켜면 X를 눌러도 시계 옆 알림 영역에 남음. 아이콘 클릭으로 다시 열기, 우클릭 > 종료로 완전히 종료 (기본 꺼짐)
- 오버레이에서 Enter: 창을 바로 숨기고 전송. Escape: 초안을 유지하고 닫기
- 연속으로 보낸 문장은 앞 음성이 끝난 다음 순서대로 재생
- 최근 대화: 실제 재생에 성공한 문장 최대 3개 자동 보관, 다시 전송, 삭제
- Enter 전송 즉시 입력창 비우기. 생성 중 새로 입력한 문장은 유지
- 생성 실패 시 전송했던 문장을 입력창에 복원
- 사운드보드 기능

최근 대화는 앱을 다시 켜도 유지되며, 네 번째 문장이 추가되면 가장 오래된 문장은 삭제됩니다.
이전 버전의 수동 저장 문장은 데이터 파일에 유지되지만 최근 대화 화면에는 표시하지 않습니다.

오버레이는 마우스가 있는 모니터에 열립니다. 게임은 테두리 없는 창 모드 또는 창 모드에서 사용하세요.
독점 전체 화면이나 관리자 권한 게임에서는 단축키/오버레이 표시가 제한될 수 있습니다.
Space 자체는 게임에도 전달되므로 점프 등 게임의 Space 동작이 함께 일어날 수 있습니다.
Space+Enter는 Windows 전용 키 조합 감지기를 사용합니다. 단축키용 Enter만 소비하며 일반 입력 내용은 수집/저장/전송하지 않습니다.
두 키를 모두 놓은 뒤 창을 열어 Enter 재입력과 Space 반복 입력을 방지합니다. 일부 게임/보안 프로그램은 키 감지를 제한할 수 있습니다.
알림 영역 아이콘이 안 보이면 시계 옆 숨겨진 아이콘 메뉴를 확인하세요. 백그라운드에서도 음성 송출과 단축키는 유지됩니다.
전송에 실패한 문장은 다음에 오버레이를 열 때 다시 표시됩니다.

Discord 세팅/해제는 각 항목의 준비와 적용 결과를 기다리고, 누락되면 해당 단계만 최대 3번 재시도합니다.
느린 PC에서는 최대 약 90초가 걸릴 수 있습니다. 동작 중에는 Discord 창을 가리지 마세요.
